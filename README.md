**底层原理**：
Python 相当于 AI 的母语，而 `ultralytics` 是 YOLO 的官方工具箱（里面包含了模型、训练脚本）。直接敲 `pip` 报错是因为环境变量没配好，用 `python -m pip` 意思是让 Python 自己去叫醒 pip 模块帮我干活。装 `ultralytics` 的时候，系统自动顺带装了 PyTorch（底层数学引擎）和 OpenCV（图像处理库）。

## 二、 试车（用官方模型跑通推理）

**我干了啥**：
建了一个 `test.py`，加载了官方的 `yolov8n.pt` 模型，让它去识别一张 7 个人跑步的照片。它成功框出了 7 个人，耗时 34.9ms。

**底层原理**：
这叫“冒烟测试”，先看看环境通不通。这个 `yolov8n.pt` 是官方预训练好的“通识生”，它的脑子里只有 COCO 的 80 个类别（人、车、狗等），所以它能认出人，但它绝对认不出手语。
输出结果里的 `cls` 代表类别（0 代表人），`conf` 代表置信度（它有多大把握），`xyxy` 是框在图片里的坐标。34.9ms 意味着 CPU 一秒钟能跑大概 28 帧。

## 三、 找食材（获取数据集与 DSH 协作）
**我干了啥**：
让 DSH 去 GitHub 找开源的手语检测项目，并检查里面的数据集格式。

**我是怎么用 DSH 的**：
我直接让它打开本地目录（防止它联网乱找），让它确认 `train/images` 里有没有文件，并让它把 `data.yaml` 的类别名和训练命令原样打印出来。

**底层原理（YOLO 的数据格式）**：
YOLO 认的教材分两部分：
1. `images` 文件夹放真实照片。
2. `labels` 文件夹放同名的 `.txt` 文件作为标准答案。

`.txt` 里的格式是 `0 0.45 0.51 0.12 0.33`。第一个数字是类别 ID（0 代表字母 A），后四位是手在图片里的**归一化坐标**（中心 x，中心 y，宽，高，都在 0 到 1 之间）。
还有一个 `data.yaml` 文件，相当于说明书，告诉模型去哪找图，一共几个类别。

## 四、 跑训练（核心环节）
**我干了啥**：
我敲下训练命令，结果报了一堆错。DSH 帮我改好了代码（改了旧版的路径和旧函数）。改好后我重新跑，看到了进度条，但因为电脑风扇太响我强行中止了。后来 DSH 用 144 张小数据集快速跑完了 1 轮，生成了模型文件。

**底层原理（训练到底在干嘛）**：
训练就是一个让 AI “做题-对答案-改错”的死循环。
1. **Batch（批次）**：`--batch 4` 表示每次只喂给 AI 4 张图，防止内存撑爆。
2. **Epoch（轮次）**：`--epochs 1` 表示把 1512 张图从头到尾完整看一遍。
3. **前向传播**：AI 看着这 4 张图，瞎猜框的位置和字母类别。
4. **计算 Loss（对答案）**：系统翻开 txt 答案，告诉 AI 你框画歪了多少（`box_loss`），字母猜错了多少（`cls_loss`）。
5. **反向传播（改脑子）**：AI 根据这个错误，微调自己内部 708 万个参数，争取下次猜准点。

**执行命令**：

```powershell
python train.py --img 320 --batch 4 --epochs 1 --data "你的data.yaml路径" --weights "你的yolov5s.pt路径" --device cpu
```

**我干了啥**：

# 基于 YOLOv5s 的 ASL 手语字母检测模型

本项目提供基于 ASL（美国手语）26 个字母的轻量级目标检测权重（`best.pt`）。
- **模型体积**：13.75MB（已剥离优化器状态）
- **推理速度**：纯 CPU 环境下约 34.9ms/帧（约 28 FPS）
- **适用场景**：端侧/本地轻量化推理

## 1. 准备工作
1. 前往本仓库的 [Releases](https://github.com/Julian-yulijin/YOLO/releases) 页面，下载 `best.pt` 模型文件。
2. 将 `best.pt` 放到本仓库 `yolov5` 目录的根目录下。
3. 确保本地已安装 Python（推荐 3.8+），执行依赖安装：
```bash
pip install -r requirements.txt
```

## 2. 快速使用
打开终端，进入 `yolov5` 目录。

**测试本地图片**：
```bash
python detect.py --weights best.pt --source 你的图片路径.jpg --img 320
```

**测试本地视频**：
```bash
python detect.py --weights best.pt --source 你的视频路径.mp4 --img 320
```

**调用电脑摄像头实时检测**：
```bash
python detect.py --weights best.pt --source 0 --img 320
```
*(注：运行后按 `q` 键退出。推理结果默认保存在 `runs/detect/exp/` 目录下。)*

## 3. 核心参数说明
- `--img 320`：**必须保留**。模型是基于 320x320 尺寸训练的，推理时保持一致才能获得最高精度和速度。
- `--conf 0.25`：默认置信度阈值。如果画面中误检较多，可调高为 `--conf 0.5`。
- `--source`：支持图片、视频路径，数字 `0` 代表默认摄像头。

## 4. 环境兼容性排障（新环境必看）
由于原版 YOLOv5 代码较老，若在最新 Python 环境下报错，请直接在源码中全局替换以下内容：
1. **找不到 `ultralytics.yolo`**：将 `ultralytics.yolo` 替换为 `ultralytics.utils`。
2. **报错 `pkg_resources`**：终端执行 `pip install "setuptools==81.0.0"`。
3. **报错 `getsize`**：将 `utils/plots.py` 中的 `getsize` 替换为 `getbbox`。
4. **报错 `np.trapz`**：将 `utils/metrics.py` 中的 `np.trapz` 替换为 `np.trapezoid`。
