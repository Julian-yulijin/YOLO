## 二、 试车（用官方模型跑通推理）

**我干了啥**：
建了一个 `test.py`，加载了官方的 `yolov8n.pt` 模型，让它去识别一张 7 个人跑步的照片。它成功框出了 7 个人，耗时 34.9ms。

**底层原理**：
这叫“冒烟测试”，先看看环境通不通。这个 `yolov8n.pt` 是官方预训练好的“通识生”，它的脑子里只有 COCO 的 80 个类别（人、车、狗等），所以它能认出人，但它绝对认不出手语。
输出结果里的 `cls` 代表类别（0 代表人），`conf` 代表置信度（它有多大把握），`xyxy` 是框在图片里的坐标。34.9ms 意味着 CPU 一秒钟能跑大概 28 帧。

**我干了啥**：
让 DSH 去 GitHub 找开源的手语检测项目，并检查里面的数据集格式。

**我是怎么用 DSH 的**：

**底层原理（YOLO 的数据格式）**：
YOLO 认的教材分两部分：
1. `images` 文件夹放真实照片。
2. `labels` 文件夹放同名的 `.txt` 文件作为标准答案。

`.txt` 里的格式是 `0 0.45 0.51 0.12 0.33`。第一个数字是类别 ID（0 代表字母 A），后四位是手在图片里的**归一化坐标**（中心 x，中心 y，宽，高，都在 0 到 1 之间）。
还有一个 `data.yaml` 文件，相当于说明书，告诉模型去哪找图，一共几个类别。

## 四、 跑训练（核心环节）
**我干了啥**：
我敲下训练命令，结果报了一堆错。DSH 帮我改好了代码（改了旧版的路径和旧函数）。改好后我重新跑，看到了进度条，但因为电脑风扇太响我强行中止了。后来 DSH 用 144 张小数据集快速跑完了 1 轮，生成了模型文件。

**底层原理（训练到底在干嘛）**：
训练就是一个让 AI “做题-对答案-改错”的死循环。
1. **Batch（批次）**：`--batch 4` 表示每次只喂给 AI 4 张图，防止内存撑爆。
2. **Epoch（轮次）**：`--epochs 1` 表示把 1512 张图从头到尾完整看一遍。
3. **前向传播**：AI 看着这 4 张图，瞎猜框的位置和字母类别。
4. **计算 Loss（对答案）**：系统翻开 txt 答案，告诉 AI 你框画歪了多少（`box_loss`），字母猜错了多少（`cls_loss`）。
5. **反向传播（改脑子）**：AI 根据这个错误，微调自己内部 708 万个参数，争取下次猜准点。

**执行命令**：

```powershell
python train.py --img 320 --batch 4 --epochs 1 --data "你的data.yaml路径" --weights "你的yolov5s.pt路径" --device cpu
```

## 五、 精简权重文件
**我干了啥**：
让 DSH 把训练出来的 `best.pt`（54MB）压缩成了 13.75MB。

**我是怎么用 DSH 的**：
直接告诉它：“对 `weights` 目录下的 pt 文件运行 `strip_optimizer`，不要训练，只做加载和保存。”

**底层原理**：
训练的时候，PyTorch 为了调整参数，会存很多中间变量（就像草稿纸），所以文件很大。现在训练完了，以后只用来认图，这些草稿纸就可以全扔了。剥离后体积缩小了 75%，非常适合以后部署到手机端。
